# ملفات المنتجات الوسيطة

ملفات منتجات (product feeds) لثلاثة متاجر سلة، مأخوذة من ملفات سلة الأصلية مع إضافة
معاملات التتبع إلى رابط كل منتج. سبب وجودها: سناب لا يقبل معاملات الرابط لإعلانات
الكتالوج إلا داخل حقل `link` لكل منتج داخل الملف نفسه، ومولّد سلة لا يتيح إضافتها.

المتاجر: عسل الجبال (`asal`)، عريش (`areesh`)، هيالة (`hayala`).
المنصات: `snap` و`meta` و`google`، لكل منصة صيغة معاملات خاصة بها.

الملفات تُحدَّث آليًّا كل يوم الساعة 02:00 بتوقيت الرياض من الجهاز المحلي
بواسطة `dashboard/publish_feeds.py` في مشروع `ads-api`.

## المحتوى

هذه الملفات تحوي أسماء المنتجات وأسعارها وصورها وروابطها فقط، وكلها منشورة أصلًا
على واجهات المتاجر. لا يحوي المستودع أي مفتاح أو رمز سرّي، ولا روابط ملفات سلة
الأصلية لأنها تحمل مقطعًا سرّيًّا.
